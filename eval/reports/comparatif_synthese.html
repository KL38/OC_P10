Ce qui marche, ce qui coince

✅ Chiffré, bruité, agrégats cœur du gain

Lookups, classements, comptages, totaux d'équipe : chiffres exacts au point près. La robustesse aux fautes (« kel joueur… ») est gratuite avec le LLM. C'est la démonstration du brief.

✅ Questions mixtes texte + chiffre

L'agent appelle spontanément les deux outils dans un même run (faithfulness 0.24 → 0.86). La ctx_precision reste basse : RAGAS pénalise une référence composée moitié texte / moitié chiffre.

⚠️ Texte : le routing régression localisée

2 questions texte mal routées vers SQL (« efficace », « combien de fois ») → réponse détruite alors que la baseline réussissait. Le corpus OCR bruité plafonne aussi les métriques de contexte.

❌ Hors-couverture : pas de refus limite majeure

Les 10 questions hors périmètre partent en SQL et sont habillées au lieu d'être refusées — jusqu'à inventer une taille (« Zubac 2,16 m »). Le garde-fou reste à implémenter.

Recommandations

  1. Question verbatim au tool RAG — ✅ fait & mesuré (faithfulness texte rétabli).

  3. Frontière de routing durcie : opinion / efficacité / histoire → RAG ; SQL réservé aux stats de la saison.
  4. Modèle SQL plus capable + ré-indexer les PDF seuls : dérivations arithmétiques (points/match) et sortie de l'Excel aplati de l'index texte.
